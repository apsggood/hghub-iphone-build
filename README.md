# HGhub iPhone 個人建置

本專案透過 GitHub Actions 編譯 HGhub 1.2.0 的 iPhone 版本。每次建置均使用相同的上游原始碼。[原始版本](https://github.com/Minireel/HGhub/tree/79827baa7542fead68919e7b45f5bfde86b18ee7)

登入 GitHub，在成功的建置紀錄下方下載 **HGhub-iPhone**，解壓縮可取得 `HGhub-1.2.0-iPhone.ipa`。下載檔保留七天，到期可在 Actions 重新執行。Windows 使用者可用自己的 Apple 帳號透過 Sideloadly 簽署並安裝到 iPhone。[建置與下載](https://github.com/apsggood/hghub-iphone-build/actions/workflows/build-iphone.yml) · [Sideloadly](https://sideloadly.io/)
